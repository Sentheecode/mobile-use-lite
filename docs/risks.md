## 1. 主线冲突（最高优先级风险）

| 项 | 说明 |
|----|------|
| 风险 | 用户主线是**宠物项圈 1.0**；本项目为旁线探索。若抢时间窗、GPU、注意力，项圈延期。 |
| 影响 | 产品主线受损；旁线本身无营收承诺。 |
| 缓解 | PRD 硬约束：冲突时暂停 Lite。里程碑不设死线绑架项圈。不开 Cloud Agent 省额度。oc + 免费档控成本。 |
| 信号 | 项圈进入冲刺/发布周 → Lite 自动降为文档-only。 |

**执行口令：** 旁线探索，勿抢项圈优先级。

---

## 2. iOS 限制

| 项 | 说明 |
|----|------|
| 风险 | iOS 沙盒导致「控整机」极难；商店应用无法任意点系统与其它 App。 |
| 影响 | 若按 Android 预期做 iOS 全自动，必失败或走向越狱/企业私有 API（不可接受）。 |
| 缓解 | 全自动主路径锁定 Android+ADB。P2 仅「本机 VL 看图建议 / 或只控自家 App」。文档非目标写死。 |
| 残余 | 建议模式仍可能被误宣传为全自动——验收文案必须带边界。 |

---

## 3. 模型能力

| 项 | 说明 |
|----|------|
| 风险 | 小模型 / 通用 VL 对密集 UI、中文小字、图标语义会点错；长程任务会漂。 |
| 影响 | P1 短路径都可能不稳；更长任务不可用。 |
| 缓解 | 短路径 3–8 步；最大轮次封顶；Sensitive gate；单轮少复合动作；P0 stub 保证工程可测。 |
| 残余 | 换更大模型会增成本，与「免费优先」冲突——需单独立项。 |

---

## 4. 额度与成本

| 项 | 说明 |
|----|------|
| 风险 | 视觉多轮烧 token；误开 Cloud Agent 或商业 Mobile-Use 造成账单。 |
| 影响 | 旁线成本失控。 |
| 缓解 | 默认 Stub + 免费 DeepSeek；截图本地；**无明确同意不开 Cloud Agent**；不绑阿里云 Mobile-Use 运行时。 |
| 残余 | 免费档限流 → `E_MODEL_RATE`；应降频而非偷换付费云。 |

---

## 5. 安全与误操作

| 项 | 说明 |
|----|------|
| 风险 | 自动点击支付、发出消息、删数据。 |
| 影响 | 资金与账号风险。 |
| 缓解 | FR-30..32；支付/验证码/登录暂停；日志脱敏；验收红线。 |
| 残余 | 启发式有漏报——P1 用人造登录页测，不保证完备。 |

---

## 6. 工程与协作

| 项 | 说明 |
|----|------|
| 风险 | 文档与实现漂移；过早建远程仓库/Origin 分散焦点。 |
| 影响 | 旁线变半吊子多仓库。 |
| 缓解 | 先文档后代码；变更先改 PRD/api；**现在不建远程、不 push**；Origin 可挂但是后话。 |
| 残余 | 多工具（oc / Cursor）切换时约定以本文档为 SSOT。 |

---

## 7. 设备与环境

| 项 | 说明 |
|----|------|
| 风险 | ADB 不稳、分辨率差异、厂商层手势差异。 |
| 影响 | P1 剧本「有时过有时不过」。 |
| 缓解 | 固定一台测试机与分辨率写进剧本；坐标公式单测；失败重试有限次。 |
